Mechanistic interpretability, Alignment

From Stethoscope to Scalpel: Making Feature Geometry Prescriptive for Fine-Tuning

  • Yuxiao LiIndependent

Feature geography can diagnose where models differ, but it does not yet reliably say which layers should be fine-tuned. This project combines representation diagnostics, adapter-update structure, and training-regime evidence into a tested layer-selection procedure.

About the project

Current interpretability tools can produce similar feature-divergence profiles for models that need opposite fine-tuning strategies. Diagnosis therefore is not yet prescription.

The project compares SAE and Jacobian-lens signals, studies per-layer adapter updates, tests supervised versus reinforcement-learning regimes, and validates the resulting procedure across model families and tasks.

Theory of change

A reliable answer to which layers an adaptation should touch can reduce unwanted capability loss and preserve unrelated safety training while producing more auditable fine-tuning decisions.

Your role

Each mentee owns one workstream from experiments through figures and writing, with detailed review and shared integration.

Prerequisites

  • High proficiency in Python and PyTorch.
  • Experience fine-tuning a transformer language model and running GPU jobs.
  • Familiarity with mechanistic-interpretability probes and linear algebra.

Application questions

  • Propose a falsifiable explanation for why similar feature profiles can imply opposite late-layer LoRA outcomes.
  • Name one fine-tuning question a Jacobian lens can answer that an SAE cannot, and one in the other direction.
