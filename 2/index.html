NAME
     suntools - the SunTools window environment

SYNOPSIS
     [ setenv PATH ${PATH}:/usr/suntool ]
     suntools [ -n | -s startup-file ]
     mouse device [ - red green
     blue [ -b red green blue ] ]

GETTING STARTED
     Suntools starts up the window environment and
     awaits the user's directives. If the environment
     has not been initialized, the invocation of sun-
     tools will fail; see suntools(1). If
     there is a file called .suntools in your home direc-
     tory, suntools starts up the tools
     specified in that file. The file format is
     described in detail below.
