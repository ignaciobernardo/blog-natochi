# Instalar

Necesitas Python 3.10+ y uv.

$ uv tool install git+https://github.com/ignaciobernardo/planes

¿Prefieres pipx? pipx install git+https://github.com/ignaciobernardo/planes

# Qué hace

El caso principal: sabes tu renta y quieres saber qué planes te cubre el 7% obligatorio sin pagar un peso más. Con una renta imponible de $2.500.789 son 411 de 929 planes con cobertura hospitalaria completa.

queplan cotizar 
$ queplan cotizar --renta 2500789 --cotizante 28:M --min-hosp 100 --min-amb 80

# Comandos

Todos aceptan --format table|json|csv, así que puedes encadenarlos con jq o abrirlos en una planilla.

cotizar

Rankea los planes por cuánto pagas sobre tu 7%. El comando principal.

isapres

Las 7 isapres abiertas con sus códigos.

planes

Filtra por isapre, cobertura mínima, modalidad, prestador o texto libre.

plan

Ficha completa: coberturas, restricciones y tabla de prestadores preferentes.

cobertura

Topes y porcentajes por prestación, buscables por nombre.

factores

Tabla de factores de riesgo por edad y sexo del plan.

precio

Precio real en UF y pesos para tu grupo familiar, con cargas.

puntaje

Desglose del puntaje por categoría y por prestador.

contrato

Descarga el PDF del contrato del plan.

export

El catálogo completo en CSV para analizarlo donde quieras.

Pensado para pipear. En --format json o csv la salida sale limpia por stdout: el progreso y los avisos van a stderr, y no se trunca a menos que pases --limit.

# Cómo funciona

QuePlan.cl es una SPA en Angular que consume una API JSON pública. El CLI habla directo con esa API — no hay scraping de HTML — y cachea todo en disco por 12 horas. Una cotización completa demora ~45 s la primera vez y ~0,2 s después.

Nada de lo que escribes sale de tu máquina más allá de la consulta. El CLI no manda tu RUT, tu nombre ni tu correo: la renta y la edad solo se usan para pedir el precio del plan. No hay formulario de contacto ni generación de leads.
